## Getting Started

If you're new to this project, start with:

1. Read the [SETUP.md](SETUP.md) to set up your development environment
2. Review [ARCHITECTURE.md](ARCHITECTURE.md) to understand the system design
3. Explore [API.md](API.md) to learn about available endpoints
4. Check the [Frontend README](../packages/frontend/README.md) for UI-specific information
5. Check the [Backend README](../packages/backend/README.md) for backend-specific information

## Contributing

When contributing to this project:

- Follow the coding standards defined in ESLint and TypeScript configs
- Keep types in the `@ct-billingtool/shared` package synchronized with backend DTOs
- Update relevant documentation when making changes
- Test locally before pushing changes
